# 回调机制 - 使用手册

## 功能说明

任务完成后自动将结果通过 HTTP POST 发送到指定的回调地址，适用于与外部系统（如 AgentHub 平台）集成。

## 配置方式

### 方式1：全局配置（通过 API）

```
POST /api/v1/callback/config
{
  "enabled": true,
  "url": "https://your-agent-hub.com/api/callback"
}
```

所有任务完成后都会发送到此地址。

### 方式2：全局配置（修改配置文件）

编辑 `config/base_config.py`：

```python
CALLBACK_ENABLED = True
CALLBACK_URL = "https://your-agent-hub.com/api/callback"
CALLBACK_MAX_RETRIES = 3
CALLBACK_RETRY_INTERVALS = [5, 15, 30]
```

### 方式3：任务级覆盖

提交任务时传入 `callback_url`：

```json
{
  "urls": ["https://..."],
  "callback_url": "https://other-service.com/receive"
}
```

**优先级**：任务级 `callback_url` > 全局配置

### 前端配置

1. 侧边栏 → "回调设置" → 填写全局回调地址并开启
2. 链接检测页 → 展开"回调配置（可选）" → 填写任务级回调地址

## 回调内容

### 主结果回调（event: task_completed）

```json
{
  "event": "task_completed",
  "task_id": "batch-abc123",
  "status": "completed",
  "timestamp": "2026-05-12T15:30:00+00:00",
  "data": { "task_id": "...", "total": 3, "results": [...] }
}
```

### 评论回调（event: comments_ready）

如果任务开启了评论抓取，会在主结果之后单独发送：

```json
{
  "event": "comments_ready",
  "task_id": "batch-abc123",
  "status": "completed",
  "timestamp": "2026-05-12T15:30:05+00:00",
  "data": { "task_id": "...", "total_comments": 30, "results": [...] }
}
```

## 重试机制

- 最多重试 3 次
- 间隔：5 秒 → 15 秒 → 30 秒
- 全部失败后记录到服务端日志

## 接收方要求

回调接收方需要：
1. 提供一个 HTTP POST 接口
2. 接受 `Content-Type: application/json` 请求
3. 返回 2xx 状态码表示成功
4. 无需认证（当前版本不支持 Token/签名）

## 查看配置状态

```
GET /api/v1/callback/config
```

返回当前全局配置。注意：通过 API 修改的配置仅运行时生效，重启后恢复默认。如需持久化，请修改 `config/base_config.py`。
