# 本地终端测试手册

> 本手册使用标准 Python/uv 命令行指令，适用于 Windows / Linux / macOS。
> 工作目录：项目根目录（如 `C:\hzww\Code\MediaCrawler`）

---

## 一、前置条件

```bash
# 确认 uv 和 Python 可用
uv --version
python --version

# 安装/同步依赖
uv sync

# 安装 Playwright 浏览器驱动
uv run playwright install chromium
```

---

## 二、命令参数说明

### 2.1 main.py 核心参数


| 参数                  | 说明              | 可选值                                              | 示例                              |
| ------------------- | --------------- | ------------------------------------------------ | ------------------------------- |
| `--type`            | 爬虫类型            | `url_check`                                      | `--type url_check`              |
| `--lt`              | 登录方式            | `qrcode`, `phone`, `cookie`, `cookie_pool`       | `--lt cookie_pool`              |
| `--urlcheck_source` | URL来源           | `file`, `db`                                     | `--urlcheck_source file`        |
| `--urlcheck_file`   | URL文件路径（file模式） | 任意 txt 文件                                        | `--urlcheck_file test_url.txt`  |
| `--headless`        | 是否无头浏览器         | `true`, `false`                                  | `--headless true`               |
| `--extract_mode`    | 指标提取模式          | `hardcode_first`, `hardcode_only`, `ai`          | `--extract_mode hardcode_first` |
| `--urlcheck_mode`   | 检测模式            | `both`(有效性+指标), `validity`(仅有效性), `metrics`(仅指标) | `--urlcheck_mode both`          |


### 2.2 uvicorn 启动参数


| 参数            | 说明           | 示例                                 |
| ------------- | ------------ | ---------------------------------- |
| `api.app:app` | FastAPI 应用入口 | 固定写法                               |
| `--host`      | 监听地址         | `0.0.0.0`(所有网卡) 或 `127.0.0.1`(仅本机) |
| `--port`      | 监听端口         | `8888`                             |
| `--reload`    | 开发模式热重载      | 加上即启用                              |


### 2.3 cookie_collector.py 参数


| 参数                   | 说明               | 可选值                                 | 示例                           |
| -------------------- | ---------------- | ----------------------------------- | ---------------------------- |
| `--platforms` / `-p` | 目标平台             | `dy`, `bili`, `ks`, `wb`, `toutiao` | `-p dy ks`                   |
| `--storage` / `-s`   | 存储模式             | `db`(MySQL,默认), `file`(JSON)        | `-s db`                      |
| `--file` / `-f`      | JSON文件路径（file模式） | 路径字符串                               | `-f config/cookie_pool.json` |
| `--timeout` / `-t`   | 扫码超时(秒)          | 整数                                  | `-t 120`                     |
| `--single`           | 单平台单账号模式         | 无值标志                                | `--single`                   |

## 三、终端原生功能测试（不启动 API）

### 测试1：基础 url_check — Cookie池 + 智能提取

```bash
uv run main.py --type url_check --lt cookie_pool --urlcheck_source file --urlcheck_file test_url_dycookie.txt --headless true
```

**说明：** 从数据库加载Cookie池，对 `test_url_dycookie.txt` 中的URL做有效性检测+指标提取。

**预期结果：**

- 日志显示 `从数据库加载 N 条Cookie`
- 快手视频成功获取指标（点赞/播放量等）
- 生成 Excel 报表到 `data/url_check/excel/`

---

### 测试2：多平台有效URL测试

```bash
uv run main.py --type url_check --lt cookie_pool --urlcheck_source file --urlcheck_file test_url_dycookie_valid.txt --headless true
```

**说明：** 测试抖音、快手、B站、微博、头条全平台有效链接。

**预期结果：**

- 各平台均成功获取数据
- Cookie切换机制正常（dy_01失效时自动切换到dy_02）
- 无效Cookie不影响其他URL处理

---

### 测试3：全无效URL测试

```bash
uv run main.py --type url_check --lt cookie_pool --urlcheck_source file --urlcheck_file test_url_dycookie_unvalid.txt --headless true
```

**说明：** 测试全部无效链接的识别准确率。

**预期结果：**

- 404 链接在HTTP预检阶段直接标记失效
- 内容已删除的链接通过API/DOM检测标记
- Cookie不被误扣失败次数

---

### 测试4：仅硬编码提取模式

```bash
uv run main.py --type url_check --lt cookie_pool --urlcheck_source file --urlcheck_file test_url_dycookie_valid.txt --headless true --extract_mode hardcode_only
```

**说明：** 只使用硬编码字段映射提取指标，不调用AI。

**预期结果：**

- 日志输出 `硬编码提取(hardcode_only):`
- 不调用 AI 接口（0 tokens 消耗）
- 部分平台指标可能不完整（这是预期行为）

---

### 测试5：仅有效性检测模式

```bash
uv run main.py --type url_check --lt cookie_pool --urlcheck_source file --urlcheck_file test_url_dycookie_valid.txt --headless true --urlcheck_mode validity
```

**说明：** 只检测链接有效性，不提取指标。

**预期结果：**

- 只输出 is_valid 状态（1=有效, 2=无效）
- 不调用 AI
- 执行速度更快

---

### 测试6：Cookie 收集 — 扫码存入数据库

```bash
uv run python tools/cookie_collector.py --platforms dy --storage db --single
```

**说明：** 打开浏览器，扫码登录抖音，将Cookie直接写入MySQL数据库。

**预期结果：**

- 弹出浏览器窗口，导航到 douyin.com
- 扫码后输出 `[DB] Cookie 已写入数据库: platform=dy id=dy_XX`
- 数据库 `cookie_pool` 表新增一条记录

---

### 测试7：Cookie 收集 — 存入本地JSON

```bash
uv run python tools/cookie_collector.py --platforms dy --storage file --single
```

**说明：** 扫码登录后将Cookie保存到本地JSON文件。

**预期结果：**

- 扫码后 Cookie 写入 `config/cookie_pool.json`
- JSON 中包含 `valid: true, fatal_count: 0`

---

### 测试8：Cookie 批量收集（多平台交互）

```bash
uv run python tools/cookie_collector.py --platforms dy ks bili --storage db
```

**说明：** 依次为抖音、快手、B站扫码收集Cookie，支持每个平台添加多个账号。

**预期结果：**

- 逐平台弹出浏览器
- 每个平台可选择继续添加或跳过
- 完成后显示数据库统计

## 四、API 接口测试

### 4.0 启动 API 服务

```bash
uv run uvicorn api.app:app --host 0.0.0.0 --port 8888
```

等待输出 `Uvicorn running on http://0.0.0.0:8888` 后，**另开一个终端窗口**执行以下测试。

> 以下使用 `curl` 命令（Windows 10+ 自带 curl.exe）。
> 如果你使用 Postman/Apifox 等工具，直接参考 URL 和请求体即可。

---

### 4.1 健康检查

```bash
curl http://localhost:8888/api/v1/health
```

**预期：** `{"status":"ok","version":"1.0.0"}`

---

### 4.2 查看 Cookie 池

```bash
# 查看全部平台
curl http://localhost:8888/api/v1/cookies

# 查看指定平台
curl "http://localhost:8888/api/v1/cookies?platform=dy"
```

**预期：** 返回 `pool` 和 `stats` 字段

---

### 4.3 添加 Cookie

```bash
curl -X POST http://localhost:8888/api/v1/cookies/add -H "Content-Type: application/json" -d "{\"platform\":\"dy\",\"cookie\":\"sessionid=test_123;\",\"note\":\"测试添加\"}"
```

**预期：** `{"success":true,"cookie_id":"dy_XX",...}`

---

### 4.4 删除 Cookie

```bash
curl -X POST http://localhost:8888/api/v1/cookies/remove -H "Content-Type: application/json" -d "{\"platform\":\"dy\",\"cookie_id\":\"dy_XX\"}"
```

**预期：** `{"success":true,...}`

---

### 4.5 重新加载 Cookie 池

```bash
curl -X POST http://localhost:8888/api/v1/cookies/reload
```

**预期：** `{"success":true,"message":"Cookie池已重新加载..."}`

---

### 4.6 扫码登录 — 启动会话

```bash
curl -X POST "http://localhost:8888/api/v1/cookies/scan/start?platform=dy&note=终端测试"
```

**预期：** 返回 `success=true` 和 8位 `cookie_id`（即 session_id）

---

### 4.7 扫码登录 — 获取二维码截图

```bash
# 将上一步返回的 cookie_id 替换 {session_id}
curl http://localhost:8888/api/v1/cookies/scan/qrcode/{session_id}
```

**预期：** `status=waiting`，包含 `qrcode_base64` 字段（base64编码的PNG截图）

---

### 4.8 扫码登录 — 轮询状态

```bash
curl http://localhost:8888/api/v1/cookies/scan/status/{session_id}
```

**预期：** `status` 为 `waiting`/`success`/`timeout` 之一

---

### 4.9 单链接检测

```bash
curl -X POST http://localhost:8888/api/v1/check/url -H "Content-Type: application/json" -d "{\"url\":\"https://www.douyin.com/video/7628682927572997561\",\"mode\":\"both\",\"enable_comments\":false}"
```

**预期：** 返回 `result` 字段，包含 `is_valid`, `praise_count` 等指标

---

### 4.10 批量 URL 检测

```bash
curl -X POST http://localhost:8888/api/v1/check/batch -H "Content-Type: application/json" -d "{\"urls\":[\"https://www.douyin.com/video/7628682927572997561\",\"https://www.bilibili.com/video/BV1godYBUE3f\"],\"mode\":\"both\",\"enable_comments\":false}"
```

**预期：** 返回 `task_id` 和 `status=pending`

---

### 4.11 查询任务进度

```bash
# 用上一步返回的 task_id
curl http://localhost:8888/api/v1/task/{task_id}
```

**预期：** `status` 为 `running` 或 `completed`，包含 `progress`, `total`, `processed` 字段

---

### 4.12 下载结果 Excel

```bash
# 任务完成后下载
curl -o result.xlsx http://localhost:8888/api/v1/task/{task_id}/result
```

**预期：** 下载成功，文件大小 > 0

---

### 4.13 MySQL 数据源检测

```bash
curl -X POST http://localhost:8888/api/v1/check/mysql -H "Content-Type: application/json" -d "{\"host\":\"123.158.253.65\",\"port\":30148,\"user\":\"root\",\"password\":\"syyq12WER45!@#!\",\"database\":\"db_sdga_report\",\"table\":\"bigscreen_data_test\",\"url_column\":\"url\",\"mode\":\"both\",\"batch_size\":5}"
```

**预期：** 返回 `task_id`，可通过 `/task/{id}` 轮询进度

---

### 4.14 错误处理测试

```bash
# 不存在的任务ID → 预期 404
curl http://localhost:8888/api/v1/task/not_exist_id

# 不存在的扫码session → 预期 404
curl http://localhost:8888/api/v1/cookies/scan/status/bad_session
```

## 五、常用组合命令速查

```bash
# 快速测试单个快手链接
uv run main.py --type url_check --lt cookie_pool --urlcheck_source file --urlcheck_file test_url_dycookie.txt --headless true

# 全平台有效链接测试
uv run main.py --type url_check --lt cookie_pool --urlcheck_source file --urlcheck_file test_url_dycookie_valid.txt --headless true

# 全平台无效链接测试
uv run main.py --type url_check --lt cookie_pool --urlcheck_source file --urlcheck_file test_url_dycookie_unvalid.txt --headless true

# 启动 API 服务
uv run uvicorn api.app:app --host 0.0.0.0 --port 8888

# 快手扫码添加Cookie到数据库
uv run python tools/cookie_collector.py --platforms ks --storage db --single

# 多平台批量扫码
uv run python tools/cookie_collector.py --platforms dy ks bili wb toutiao --storage db

# 结束进程
taskkill /F /PID (netstat -ano | findstr ":8888" | ForEach-Object { $_.Split()[-1] })

# 找到占用8888的进程ID
netstat -ano | findstr ":8888"

# 杀掉它（把最后面的数字替换成你查到的 PID）
taskkill /F /PID 数字
```
