# MediaCrawler 前端管理页面 — 使用手册

## 1. 环境要求

- Node.js >= 18（推荐 20+）
- npm >= 9
- 后端 API 服务已启动（默认 `http://localhost:8888`）

## 2. 安装与启动

```bash
# 进入前端目录
cd frontend

# 安装依赖（首次运行）
npm install

# 启动开发服务器
npm run dev
```

启动成功后控制台显示：

```
VITE v6.x.x  ready in xxxx ms
  ➜  Local:   http://localhost:5173/
```

浏览器打开 `http://localhost:5173/` 即可使用。

## 3. 后端 API 连接

- **开发模式**：Vite 自动将 `/api` 请求代理到 `http://localhost:8888`，无需额外配置
- **自定义后端地址**：创建 `frontend/.env.local` 文件，添加：
  ```
  VITE_API_BASE=http://你的服务器IP:8888
  ```

## 4. 页面功能说明

### 4.1 概览（Dashboard）

首页展示系统整体状态：

| 卡片 | 说明 |
|------|------|
| API 状态 | 显示后端服务是否正常连接 |
| 有效 Cookie | 当前 Cookie 池中有效的 Cookie 总数 |
| 失效 Cookie | 已被标记为失效的 Cookie 数量 |
| 覆盖平台数 | 已配置 Cookie 的平台数量 |

下方有各平台 Cookie 明细表格和快捷操作按钮。

### 4.2 链接检测（URL Check）

提供 4 种检测方式，通过 Tab 切换：

#### 单条检测
1. 在 URL 输入框粘贴要检测的链接
2. 选择检测模式（完整检测/仅有效性/仅指标）
3. 点击「开始检测」
4. 结果实时显示在下方卡片中（平台、有效性、点赞数、评论数等）

#### 批量检测
1. 在文本框中粘贴 URL，每行一个
2. 选择检测模式
3. 点击「提交批量检测」
4. 自动跳转到「任务管理」页查看进度

#### 文件上传
1. 拖拽或点击选择文件（支持 .xlsx / .csv / .txt）
2. 填写 URL 所在列名（默认 `url`）
3. 点击「上传并检测」

#### MySQL 数据源
1. 填写数据库连接信息（主机、端口、用户名、密码、数据库名、表名）
2. 设置 URL 列名、批量大小、检测模式
3. 点击「提交 MySQL 检测」
4. **检测结果会自动回写到同一张数据库表**

### 4.3 任务管理（Task List）

管理所有异步检测任务：

- **任务列表**：展示任务 ID、状态、进度条、消息
- **自动轮询**：运行中的任务每 3 秒自动刷新进度
- **手动查询**：在搜索框输入 Task ID 可查询指定任务
- **下载结果**：任务完成后点击「下载 Excel」获取结果文件
- **日志栏**：底部显示任务处理的实时日志

### 4.4 Cookie 管理

管理 Cookie 池中的所有 Cookie：

- **查看列表**：按平台展示 Cookie ID、状态（有效/失效）、失败次数、备注
- **按平台筛选**：下拉框可筛选特定平台的 Cookie
- **添加 Cookie**：点击「添加 Cookie」按钮，选择平台、粘贴 Cookie 字符串、填写备注
- **删除 Cookie**：点击行末的删除按钮，确认后删除
- **重新加载**：点击「重新加载」从数据库/文件重新加载 Cookie 池
- **统计信息**：底部展示各平台的有效/失效 Cookie 数量

### 4.5 扫码登录

通过浏览器扫码为各平台获取 Cookie：

1. 选择平台：可选「全部平台（串行扫码）」或单个平台
2. 填写备注（可选）
3. 点击「开始扫码」
4. 页面左侧显示当前平台的二维码截图
5. 用对应平台的 App 扫描二维码
6. 右侧时间轴展示各平台的扫码进度（已完成/进行中/已跳过）
7. 每个平台超时时间为 120 秒，超时自动跳过下一个

## 5. 生产部署

```bash
# 构建生产版本
cd frontend
npm run build

# 产出在 frontend/dist/ 目录
# 使用 Nginx 或其他 Web 服务器托管该目录
```

Nginx 配置示例：

```nginx
server {
    listen 80;
    server_name your-domain.com;

    # 前端静态文件
    location / {
        root /path/to/frontend/dist;
        try_files $uri $uri/ /index.html;
    }

    # API 反向代理
    location /api/ {
        proxy_pass http://127.0.0.1:8888;
        proxy_set_header Host $host;
    }
}
```

## 6. 常见问题

| 问题 | 解决方法 |
|------|----------|
| 页面打开空白 | 检查 `npm run dev` 是否正常启动，终端是否有报错 |
| API 请求 404 | 确认后端已启动在 8888 端口，检查 Vite 代理配置 |
| Cookie 数据加载失败 | 确认后端配置了 `ENABLE_COOKIE_POOL=True`，数据库连接正常 |
| 扫码二维码不显示 | 后端需在有桌面环境的机器上运行（Playwright 需要浏览器窗口） |
| 文件上传失败 | 检查文件格式（.xlsx/.csv/.txt），确认列名是否正确 |
