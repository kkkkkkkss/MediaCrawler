# 服务器部署测试手册

> 适用于远程 Windows/Linux 服务器部署。所有 `<SERVER_IP>` 替换为实际服务器公网 IP。

---

## 一、环境搭建

### Linux 服务器

```bash
# 安装 Python 3.10+
sudo apt update && sudo apt install -y python3.10 python3.10-venv

# 安装 uv
curl -LsSf https://astral.sh/uv/install.sh | sh

# 克隆项目
cd /opt
git clone <YOUR_REPO_URL> MediaCrawler
cd MediaCrawler

# 安装依赖
uv sync

# 安装浏览器（需要 root 或 sudo）
uv run playwright install chromium
uv run playwright install-deps
```

### Windows 服务器

```powershell
# 安装 Python 3.10+ (从 python.org)
# 安装 uv
powershell -c "irm https://astral.sh/uv/install.ps1 | iex"

# 克隆项目
cd C:\hzww\Code
git clone <YOUR_REPO_URL> MediaCrawler
cd MediaCrawler

# 安装依赖
uv sync

# 安装浏览器
uv run playwright install chromium
```

## 三、数据库建表

连接 MySQL 执行：

```sql
CREATE TABLE IF NOT EXISTS cookie_pool (
    id INT AUTO_INCREMENT PRIMARY KEY,
    platform VARCHAR(20) NOT NULL COMMENT '平台: dy/bili/ks/wb/toutiao',
    cookie_id VARCHAR(50) NOT NULL COMMENT 'Cookie唯一ID',
    cookie_str TEXT NOT NULL COMMENT 'Cookie字符串',
    note VARCHAR(200) DEFAULT '' COMMENT '备注',
    is_valid TINYINT DEFAULT 1 COMMENT '1=有效 0=失效',
    fatal_count INT DEFAULT 0 COMMENT '致命失败累计次数',
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    updated_at DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    UNIQUE KEY uk_platform_cookie_id (platform, cookie_id),
    INDEX idx_platform_valid (platform, is_valid)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='Cookie池';
```

## 五、启动服务

### Linux — systemd

```bash
cat > /etc/systemd/system/mediacrawler-api.service << 'EOF'
[Unit]
Description=MediaCrawler API
After=network.target

[Service]
Type=simple
WorkingDirectory=/opt/MediaCrawler
ExecStart=/root/.local/bin/uv run uvicorn api.app:app --host 0.0.0.0 --port 8888
Restart=always
RestartSec=5

[Install]
WantedBy=multi-user.target
EOF

systemctl daemon-reload
systemctl enable mediacrawler-api
systemctl start mediacrawler-api
systemctl status mediacrawler-api
```

### Windows — NSSM

```powershell
nssm install MediaCrawlerAPI "C:\Users\<USER>\.local\bin\uv.exe" "run uvicorn api.app:app --host 0.0.0.0 --port 8888"
nssm set MediaCrawlerAPI AppDirectory "C:\hzww\Code\MediaCrawler"
nssm start MediaCrawlerAPI
```

### 验证启动

```bash
curl http://<SERVER_IP>:8888/api/v1/health
# 预期: {"status":"ok","version":"1.0.0"}
```

## 七、API 接口测试（curl 版）

> 以下所有 `<SERVER_IP>` 替换为服务器实际 IP。本机测试用 `127.0.0.1`。

### 7.1 健康检查

```bash
curl -s http://<SERVER_IP>:8888/api/v1/health | python3 -m json.tool
```

### 7.2 查看 Cookie 池

```bash
curl -s "http://<SERVER_IP>:8888/api/v1/cookies?platform=dy" | python3 -m json.tool
```

### 7.3 添加 Cookie

```bash
curl -s -X POST http://<SERVER_IP>:8888/api/v1/cookies/add \
  -H "Content-Type: application/json" \
  -d '{"platform":"dy","cookie":"sessionid=test123;","note":"服务器测试"}' | python3 -m json.tool
```

### 7.4 删除 Cookie

```bash
curl -s -X POST http://<SERVER_IP>:8888/api/v1/cookies/remove \
  -H "Content-Type: application/json" \
  -d '{"platform":"dy","cookie_id":"dy_XX"}' | python3 -m json.tool
```

### 7.5 重新加载 Cookie 池

```bash
curl -s -X POST http://<SERVER_IP>:8888/api/v1/cookies/reload | python3 -m json.tool
```

### 7.6 扫码登录 — 启动

```bash
curl -s -X POST "http://<SERVER_IP>:8888/api/v1/cookies/scan/start?platform=dy&note=远程扫码" | python3 -m json.tool
# 记录返回的 cookie_id 作为 SESSION_ID
```

### 7.7 扫码登录 — 获取二维码

```bash
SESSION_ID="替换为上一步的ID"
curl -s "http://<SERVER_IP>:8888/api/v1/cookies/scan/qrcode/$SESSION_ID" | python3 -m json.tool
```

### 7.8 扫码登录 — 轮询状态

```bash
curl -s "http://<SERVER_IP>:8888/api/v1/cookies/scan/status/$SESSION_ID" | python3 -m json.tool
```

### 7.9 单链接检测

```bash
curl -s -X POST http://<SERVER_IP>:8888/api/v1/check/url \
  -H "Content-Type: application/json" \
  -d '{"url":"https://www.iesdouyin.com/share/video/7628682927572997561","mode":"both","enable_comments":false}' | python3 -m json.tool
```

### 7.10 批量 URL 检测

```bash
curl -s -X POST http://<SERVER_IP>:8888/api/v1/check/batch \
  -H "Content-Type: application/json" \
  -d '{"urls":["https://www.iesdouyin.com/share/video/7628682927572997561","https://www.iesdouyin.com/share/video/7628889655614035109/?schema_type=37"],"mode":"both","enable_comments":false}' | python3 -m json.tool
# 记录 task_id
```

### 7.11 查询任务进度

```bash
TASK_ID="替换为上一步的task_id"
sleep 15
curl -s "http://<SERVER_IP>:8888/api/v1/task/$TASK_ID" | python3 -m json.tool
```

### 7.12 下载结果

```bash
curl -o result.xlsx "http://<SERVER_IP>:8888/api/v1/task/$TASK_ID/result"
ls -la result.xlsx
```

### 7.13 MySQL 数据源检测

```bash
curl -s -X POST http://<SERVER_IP>:8888/api/v1/check/mysql \
  -H "Content-Type: application/json" \
  -d '{
    "host":"123.158.253.65",
    "port":30148,
    "user":"root",
    "password":"syyq12WER45!@#!",
    "database":"db_sdga_report",
    "table":"bigscreen_data_test",
    "url_column":"url",
    "mode":"both",
    "batch_size":5
  }' | python3 -m json.tool
```

### 7.14 上传文件检测

```bash
curl -s -X POST http://<SERVER_IP>:8888/api/v1/check/upload \
  -F "file=@test_url_dycookie.txt" \
  -F "url_column=url" \
  -F "mode=both" \
  -F "enable_comments=false" | python3 -m json.tool
```

### 7.15 错误处理验证

```bash
# 不存在的 task_id → 404
curl -s -o /dev/null -w "%{http_code}" http://<SERVER_IP>:8888/api/v1/task/not_exist

# 不存在的 session → 404
curl -s -o /dev/null -w "%{http_code}" http://<SERVER_IP>:8888/api/v1/cookies/scan/status/bad_id
```
