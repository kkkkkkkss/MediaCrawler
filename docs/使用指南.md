# 使用指南

## 一、命令行模式

### 基本用法

```bash
# 从本地txt文件检测URL（推荐入门方式）
uv run main.py --type url_check --urlcheck_source file --urlcheck_file urls.txt

# 从外部MySQL数据库读取URL
uv run main.py --type url_check --urlcheck_source db
```

### 完整参数说明


| 参数                    | 说明                                                  | 默认值     |
| --------------------- | --------------------------------------------------- | ------- |
| `--type url_check`    | 启用URL检测模式                                           | -       |
| `--urlcheck_mode`     | 检测模式：`validity`(仅有效性) / `metrics`(仅指标) / `both`(同时) | `both`  |
| `--urlcheck_source`   | 输入来源：`db`(外部MySQL) / `file`(本地txt文件)                | `db`    |
| `--urlcheck_file`     | txt文件路径（每行一个URL）                                    | -       |
| `--urlcheck_comments` | 是否同时抓取评论：`true` / `false`                           | `false` |
| `--extract_mode`      | 指标提取方式：`ai`(AI解析) / `hardcode`(硬编码取值)               | `ai`    |
| `--headless`          | 无头模式（服务器部署必须true）                                   | `false` |


### 使用示例

```bash
# 示例1：检测txt文件中的URL，同时抓取评论和生成词云
uv run main.py --type url_check \
    --urlcheck_mode both \
    --urlcheck_source file \
    --urlcheck_file example_url.txt \
    --urlcheck_comments true

uv run main.py --type url_check \
    --urlcheck_mode both \
    --urlcheck_source file \
    --urlcheck_file test_url.txt \
    --urlcheck_comments true

uv run main.py --type url_check --urlcheck_mode both --urlcheck_source file --urlcheck_file test_url.txt --urlcheck_comments true

# 示例2：仅检测链接有效性（不抓指标）
uv run main.py --type url_check \
    --urlcheck_mode validity \
    --urlcheck_source file \
    --urlcheck_file urls.txt
uv run main.py --type url_check --urlcheck_mode validity --urlcheck_source file --urlcheck_file test_url.txt

# 示例3：Playwright无头模式运行（服务器环境）
uv run main.py --type url_check \
    --urlcheck_source file \
    --urlcheck_file urls.txt \
    --headless true
uv run main.py --type url_check --urlcheck_source file --urlcheck_file test_url.txt --headless true

# 示例4：使用硬编码提取（不消耗AI token）
uv run main.py --type url_check \
    --urlcheck_source file \
    --urlcheck_file urls.txt \
    --extract_mode hardcode
uv run main.py --type url_check --urlcheck_source file --urlcheck_file test_url.txt --extract_mode hardcode
```

### 输出文件

| 文件      | 路径                                                        | 说明       |
| ------- | --------------------------------------------------------- | -------- |
| Excel报表 | `data/url_check/excel/url_check_YYYYMMDD_HHMMSS.xlsx`     | 包含全部检测结果 |
| 评论词云    | `data/url_check/words/url_check_comments_YYYY-MM-DD.png`  | 词云图片     |
| 词频统计    | `data/url_check/words/url_check_comments_YYYY-MM-DD.json` | 词频数据     |

| 列名     | 说明                   |

| 原始链接   | 输入的URL原文             |

## 二、FastAPI 服务模式

### 启动服务

```bash
# 开发环境
uv run uvicorn api.app:app --host 0.0.0.0 --port 8000 --reload

# 生产环境
uv run uvicorn api.app:app --host 0.0.0.0 --port 8000
```

启动后访问 `http://localhost:8000/docs` 查看交互式API文档。

### API 端点


| 方法   | 路径                              | 说明                  |
| ---- | ------------------------------- | ------------------- |
| GET  | `/api/v1/health`                | 健康检查                |
| POST | `/api/v1/check/url`             | 单链接检测（同步）           |
| POST | `/api/v1/check/batch`           | 批量URL检测（异步）         |
| POST | `/api/v1/check/upload`          | 上传Excel/CSV文件检测（异步） |
| POST | `/api/v1/check/mysql`           | 从MySQL读取URL检测（异步）   |
| GET  | `/api/v1/task/{task_id}`        | 查询任务进度              |
| GET  | `/api/v1/task/{task_id}/result` | 下载结果Excel           |


### 调用示例

#### 1. 单链接检测（curl）

```bash
curl -X POST http://localhost:8000/api/v1/check/url \
  -H "Content-Type: application/json" \
  -d '{
    "url": "https://www.bilibili.com/video/BV1godYBUE3f",
    "mode": "both",
    "enable_comments": false
  }'
```

响应：

```json
{
  "result": {
    "id": 1,
    "url": "https://www.bilibili.com/video/BV1godYBUE3f",
    "platform": "bili",
    "content_type": "视频",
    "author": "花叔v",
    "praise_count": 595,
    "reply_count": 291,
    "visit_count": 36306,
    "share_count": 115,
    "is_valid": 1
  },
  "message": "ok"
}
```

#### 2. 批量URL检测（curl）

```bash
# 提交任务
curl -X POST http://localhost:8000/api/v1/check/batch \
  -H "Content-Type: application/json" \
  -d '{
    "urls": [
      "https://www.douyin.com/video/7628682927572997561",
      "https://www.bilibili.com/video/BV1godYBUE3f"
    ],
    "mode": "both",
    "enable_comments": true
  }'

# 响应：{"task_id": "a1b2c3d4", "status": "pending", "message": "任务已提交"}

# 查询进度
curl http://localhost:8000/api/v1/task/a1b2c3d4

# 下载结果Excel
curl -O http://localhost:8000/api/v1/task/a1b2c3d4/result
```

#### 3. 上传Excel文件检测（curl）

```bash
curl -X POST http://localhost:8000/api/v1/check/upload \
  -F "file=@links.xlsx" \
  -F "url_column=链接" \
  -F "mode=both" \
  -F "enable_comments=false"
```

#### 4. Python 调用示例

```python
import requests
import time

API_BASE = "http://localhost:8000/api/v1"

# 批量检测
resp = requests.post(f"{API_BASE}/check/batch", json={
    "urls": [
        "https://www.bilibili.com/video/BV1godYBUE3f",
        "https://weibo.com/1987241375/QCIQEm6rM",
    ],
    "mode": "both",
})
task_id = resp.json()["task_id"]

# 轮询等待完成
while True:
    status = requests.get(f"{API_BASE}/task/{task_id}").json()
    print(f"进度: {status['progress']:.0f}%  ({status['processed']}/{status['total']})")
    if status["status"] in ("completed", "failed"):
        break
    time.sleep(5)

# 下载结果
if status["status"] == "completed":
    result = requests.get(f"{API_BASE}/task/{task_id}/result")
    with open("result.xlsx", "wb") as f:
        f.write(result.content)
    print("结果已保存至 result.xlsx")
```

## 三、支持的平台和链接格式


| 平台  | 支持的URL格式                                                                                          |
| --- | ------------------------------------------------------------------------------------------------- |
| 抖音  | `douyin.com/video/xxx`、`iesdouyin.com/share/video/xxx`                                            |
| 快手  | `kuaishou.com/short-video/xxx`、`kuaishou.com/f/xxx`（短链自动解析）、`m.kuaishou.com/notice/detail?id=xxx` |
| B站  | `bilibili.com/video/BVxxx`                                                                        |
| 微博  | `weibo.com/uid/mid`、`m.weibo.cn/detail/mid`                                                       |
| 头条  | `toutiao.com/iXXX`、`toutiao.com/article/XXX`                                                      |
| 小红书 | `xiaohongshu.com/explore/xxx`                                                                     |
