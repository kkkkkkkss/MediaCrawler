# 部署指南

## 环境要求

- Python 3.11+
- Playwright 浏览器（Chromium）
- MySQL 5.7+（外部业务库，可选）

## 环境变量配置

复制 `.env.example` 为 `.env` 并填写：

```env
# AI 字段映射（火山引擎豆包）
DOUBAO_API_KEY=你的API密钥
DOUBAO_BASE_URL=https://ark.cn-beijing.volces.com/api/v3
DOUBAO_MODEL=doubao-seed-2-0-pro-260215

# 外部业务库（url_check DB模式必填，file模式可选）
EXT_MYSQL_HOST=127.0.0.1
EXT_MYSQL_PORT=3306
EXT_MYSQL_USER=root
EXT_MYSQL_PWD=密码
EXT_MYSQL_DB=db_sdga_report

# FastAPI 服务端口
API_PORT=8000
```

## 方案一：Docker 部署（推荐）

### 1. Dockerfile

```dockerfile
FROM python:3.11-slim

# 安装系统依赖
RUN apt-get update && apt-get install -y --no-install-recommends \
    wget gnupg2 fonts-wqy-zenhei \
    && rm -rf /var/lib/apt/lists/*

WORKDIR /app

# 安装 uv
RUN pip install uv

# 复制依赖文件并安装
COPY pyproject.toml uv.lock ./
RUN uv sync --no-dev

# 安装 Playwright 浏览器
RUN uv run playwright install chromium
RUN uv run playwright install-deps chromium

# 复制项目源码
COPY . .

# 暴露端口
EXPOSE 8000

# 启动 FastAPI 服务
CMD ["uv", "run", "uvicorn", "api.app:app", "--host", "0.0.0.0", "--port", "8000"]
```

### 2. docker-compose.yml

```yaml
version: '3.8'

services:
  mediacrawler-api:
    build: .
    container_name: mediacrawler-api
    ports:
      - "8000:8000"
    env_file:
      - .env
    volumes:
      - ./data:/app/data                    # 持久化输出数据
      - ./browser_data:/app/browser_data    # 持久化浏览器Cookie
    restart: unless-stopped
    deploy:
      resources:
        limits:
          memory: 2G
          cpus: '2'
    healthcheck:
      test: ["CMD", "curl", "-f", "http://localhost:8000/api/v1/health"]
      interval: 30s
      timeout: 10s
      retries: 3
```

### 3. 构建并运行

```bash
# 构建镜像
docker-compose build

# 启动服务
docker-compose up -d

# 查看日志
docker-compose logs -f mediacrawler-api

# 停止服务
docker-compose down
```

## 方案二：systemd 直接部署

### 1. 安装依赖

```bash
# 安装 Python 3.11+ 和 uv
curl -LsSf https://astral.sh/uv/install.sh | sh

# 进入项目目录
cd /opt/mediacrawler

# 安装 Python 依赖
uv sync

# 安装 Playwright 浏览器
uv run playwright install chromium
uv run playwright install-deps chromium

# 安装中文字体（词云需要）
apt-get install -y fonts-wqy-zenhei
```

### 2. 创建 systemd 服务

```ini
# /etc/systemd/system/mediacrawler-api.service
[Unit]
Description=MediaCrawler URL Check API
After=network.target

[Service]
Type=simple
User=www-data
Group=www-data
WorkingDirectory=/opt/mediacrawler
EnvironmentFile=/opt/mediacrawler/.env
ExecStart=/opt/mediacrawler/.venv/bin/uvicorn api.app:app --host 0.0.0.0 --port 8000
Restart=on-failure
RestartSec=10
LimitNOFILE=65536

[Install]
WantedBy=multi-user.target
```

### 3. 启动服务

```bash
systemctl daemon-reload
systemctl enable mediacrawler-api
systemctl start mediacrawler-api
systemctl status mediacrawler-api

# 查看日志
journalctl -u mediacrawler-api -f
```

## 方案三：Kubernetes 部署

### 1. ConfigMap（环境变量）

```yaml
apiVersion: v1
kind: ConfigMap
metadata:
  name: mediacrawler-config
  namespace: default
data:
  DOUBAO_BASE_URL: "https://ark.cn-beijing.volces.com/api/v3"
  DOUBAO_MODEL: "doubao-seed-2-0-pro-260215"
  EXT_MYSQL_HOST: "mysql-service"
  EXT_MYSQL_PORT: "3306"
  EXT_MYSQL_DB: "db_sdga_report"
  API_PORT: "8000"
```

### 2. Secret（敏感信息）

```yaml
apiVersion: v1
kind: Secret
metadata:
  name: mediacrawler-secret
  namespace: default
type: Opaque
stringData:
  DOUBAO_API_KEY: "你的API密钥"
  EXT_MYSQL_USER: "root"
  EXT_MYSQL_PWD: "数据库密码"
```

### 3. Deployment

```yaml
apiVersion: apps/v1
kind: Deployment
metadata:
  name: mediacrawler-api
  namespace: default
spec:
  replicas: 1    # Playwright 浏览器消耗资源大，建议单副本
  selector:
    matchLabels:
      app: mediacrawler-api
  template:
    metadata:
      labels:
        app: mediacrawler-api
    spec:
      containers:
      - name: mediacrawler-api
        image: your-registry/mediacrawler-api:latest
        ports:
        - containerPort: 8000
        envFrom:
        - configMapRef:
            name: mediacrawler-config
        - secretRef:
            name: mediacrawler-secret
        resources:
          requests:
            memory: "1Gi"
            cpu: "500m"
          limits:
            memory: "2Gi"
            cpu: "2000m"
        volumeMounts:
        - name: data
          mountPath: /app/data
        - name: browser-data
          mountPath: /app/browser_data
        livenessProbe:
          httpGet:
            path: /api/v1/health
            port: 8000
          initialDelaySeconds: 30
          periodSeconds: 30
        readinessProbe:
          httpGet:
            path: /api/v1/health
            port: 8000
          initialDelaySeconds: 10
          periodSeconds: 10
      volumes:
      - name: data
        persistentVolumeClaim:
          claimName: mediacrawler-data-pvc
      - name: browser-data
        persistentVolumeClaim:
          claimName: mediacrawler-browser-pvc
```

### 4. Service

```yaml
apiVersion: v1
kind: Service
metadata:
  name: mediacrawler-api
  namespace: default
spec:
  selector:
    app: mediacrawler-api
  ports:
  - port: 8000
    targetPort: 8000
  type: ClusterIP
```

### 5. PVC（数据持久化）

```yaml
apiVersion: v1
kind: PersistentVolumeClaim
metadata:
  name: mediacrawler-data-pvc
spec:
  accessModes: [ReadWriteOnce]
  resources:
    requests:
      storage: 10Gi
---
apiVersion: v1
kind: PersistentVolumeClaim
metadata:
  name: mediacrawler-browser-pvc
spec:
  accessModes: [ReadWriteOnce]
  resources:
    requests:
      storage: 2Gi
```

### 6. 部署步骤

```bash
# 构建并推送镜像
docker build -t your-registry/mediacrawler-api:latest .
docker push your-registry/mediacrawler-api:latest

# 部署到 K8s
kubectl apply -f k8s/configmap.yaml
kubectl apply -f k8s/secret.yaml
kubectl apply -f k8s/pvc.yaml
kubectl apply -f k8s/deployment.yaml
kubectl apply -f k8s/service.yaml

# 检查状态
kubectl get pods -l app=mediacrawler-api
kubectl logs -f deployment/mediacrawler-api
```

## 注意事项

1. **Playwright 浏览器内存占用**：每个浏览器实例约 200-500MB，建议给容器至少 2GB 内存
2. **无头模式**：服务器部署必须使用 Playwright 模式（非CDP），且开启无头模式
3. **Cookie 持久化**：`browser_data` 目录存储浏览器登录状态，需要持久化存储
4. **首次登录**：第一次部署时需要手动执行一次扫码登录，后续 Cookie 会自动复用
5. **并发限制**：由于平台风控，建议任务队列 worker 数量保持为 1
