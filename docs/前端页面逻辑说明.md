# MediaCrawler 前端管理页面 — 逻辑说明

## 1. 技术架构

| 层级 | 技术 | 说明 |
|------|------|------|
| 构建工具 | Vite 6 | 极速 HMR + 生产构建 |
| 框架 | Vue 3 + Composition API | 响应式 UI 框架 |
| UI 组件库 | Element Plus | 中文企业级 Vue 3 组件 |
| HTTP 请求 | Axios | 封装为统一 API 层 |
| 路由 | Vue Router 4 | SPA 页面路由 |
| 部署方式 | 前后端分离 | 前端 5173 / 后端 8888 |

## 3. API 交互流程

### 3.1 单条检测（同步）

```
用户输入 URL → POST /api/v1/check/url → 等待响应 → 展示结果
```

前端直接 `await` API 响应，响应时间取决于平台 API 速度（通常 5-15 秒）。

### 3.2 批量/文件/MySQL 检测（异步）

```
提交请求 → 获取 task_id → 跳转任务页 → 定时轮询 GET /task/{id} → 完成后下载 Excel
```

所有异步任务遵循相同的 task_id 轮询模式：
1. 提交接口返回 `{ task_id, status: "pending" }`
2. 前端每 3 秒调用 `GET /task/{task_id}` 获取进度
3. `status === "completed"` 时停止轮询，显示下载按钮
4. 下载通过 `GET /task/{task_id}/result` 获取 blob 并触发浏览器下载

### 3.3 Cookie 管理（CRUD）

| 操作 | API | 方法 |
|------|-----|------|
| 查看列表 | GET /cookies?platform=xx | 返回按平台分组的 Cookie 列表和统计 |
| 添加 | POST /cookies/add | Body: {platform, cookie, note} |
| 删除 | POST /cookies/remove | Body: {platform, cookie_id} |
| 重新加载 | POST /cookies/reload | 从 DB/文件重新加载到内存 |

### 3.4 扫码登录（长轮询）

```
选择平台 → POST /cookies/scan/start → 获取 session_id
       ↓
  每 2 秒并行轮询：
  - GET /cookies/scan/qrcode/{session_id} → 获取 base64 截图 → 渲染为 <img>
  - GET /cookies/scan/status/{session_id} → 更新状态/时间轴
       ↓
  status === "all_done" → 停止轮询
```

## 4. 关键设计说明

### 4.1 Vite 代理

`vite.config.js` 中配置了 `/api` 路径代理到后端 `http://localhost:8888`，解决开发时跨域问题：

```javascript
proxy: {
  '/api': {
    target: 'http://localhost:8888',
    changeOrigin: true,
  },
}
```

生产环境由 Nginx 统一处理反向代理。

### 4.2 CORS

后端 `api/app.py` 添加了 CORSMiddleware，允许所有来源的跨域请求。
开发时 Vite 代理绕过了 CORS 限制，生产环境 CORS 作为额外安全保障。

### 4.3 任务持久化

`TaskList.vue` 使用 `sessionStorage` 保存当前页签的任务列表，刷新页面后任务 ID 不会丢失。
但 sessionStorage 仅在当前标签页有效，关闭浏览器后需手动输入 task_id 查询。

### 4.4 MySQL 回写机制

`POST /api/v1/check/mysql` 提交 MySQL 检测任务后：
1. 后端从用户指定的 MySQL 读取 URL（保留原始行 ID）
2. 设置 `URLCHECK_INPUT_SOURCE = "db"` 标记为数据库模式
3. 处理每条 URL 后，通过 `external_db.update_metrics()` 将结果回写到 `.env` 中配置的 `EXT_MYSQL_*` 数据库
4. 同时生成 Excel 结果文件供前端下载

### 4.5 API 层封装

`src/api/index.js` 统一管理所有 API 调用：
- 请求基础路径由环境变量 `VITE_API_BASE` 控制
- 响应拦截器自动解包 `res.data`，错误统一转为 `Error`
- 文件下载使用原始 axios 实例（需要 `responseType: 'blob'`）

## 5. 组件依赖关系

```
App.vue (布局骨架)
  ├── Dashboard.vue      → api: healthCheck, listCookies
  ├── UrlCheck.vue       → api: checkSingleUrl, checkBatchUrls, uploadFileCheck, checkMysqlSource
  ├── TaskList.vue       → api: getTaskProgress, downloadTaskResult
  ├── CookieManage.vue   → api: listCookies, addCookie, removeCookie, reloadCookies
  └── ScanLogin.vue      → api: startScan, getScanQrcode, getScanStatus
```

每个页面组件独立管理自己的状态（无全局状态管理），通过 Vue Router 切换。
