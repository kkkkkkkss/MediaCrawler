# 拟人化反风控 - 使用手册

## 功能概述

在多浏览器并发爬取场景下，通过三项拟人化措施降低平台风控触发概率：
- **错峰启动**：多个浏览器随机延迟启动，避免同一 IP 瞬间打开多个浏览器
- **请求间隔抖动**：每次请求间隔添加随机偏移，模拟人类不规律的浏览行为
- **视口尺寸随机化**：每个浏览器的窗口尺寸随机微调，降低浏览器指纹关联风险

---

## 配置说明

所有配置位于 `config/base_config.py` 的"拟人化反风控配置"区域。

### 1. 浏览器错峰启动间隔

```python
BROWSER_STAGGER_MAX_SEC = 3.0
```

| 参数值 | 效果 |
|--------|------|
| 0 | 所有浏览器同时启动（不推荐） |
| 3.0（默认） | 每个浏览器在 0~3 秒内随机延迟启动 |
| 5.0 | 更大延迟，适合高风控平台 |

**注意**：第一个 Worker（W1）始终立即启动，延迟仅作用于 W2、W3 等后续浏览器。

### 2. 请求间隔抖动比例

```python
SLEEP_JITTER_RATIO = 0.3
```

以 `PLATFORM_SLEEP_SEC` 中的基础间隔为准，添加 ±该比例的随机偏移。

| 基础间隔 | 抖动比例 | 实际间隔范围 |
|----------|---------|------------|
| 2 秒 | 0.3 | 1.4 ~ 2.6 秒 |
| 2 秒 | 0.5 | 1.0 ~ 3.0 秒 |
| 1 秒 | 0.3 | 0.7 ~ 1.3 秒 |

### 3. 视口尺寸随机偏移

```python
VIEWPORT_RANDOM_OFFSET = 50
```

每个浏览器的视口在基础尺寸 1920×1080 上随机偏移 ±该值（像素）。

| 偏移值 | 实际视口范围 |
|--------|------------|
| 0 | 固定 1920×1080（所有浏览器相同，不推荐） |
| 50（默认） | 宽 1870~1970，高 1030~1130 |
| 100 | 宽 1820~2020，高 980~1180 |

## 配合已有配置使用

拟人化配置与并发配置协同工作：

```python
# 并发配置
PLATFORM_CONCURRENCY = {
    "dy": 2,        # 抖音开 2 个浏览器
    "toutiao": 3,   # 头条开 3 个浏览器
}

# 拟人化配置
BROWSER_STAGGER_MAX_SEC = 3.0   # 浏览器间隔 0~3 秒错峰启动
SLEEP_JITTER_RATIO = 0.3        # 请求间隔 ±30% 抖动
VIEWPORT_RANDOM_OFFSET = 50     # 视口 ±50px 随机化
```

## 前端日志格式

批量检测时，前端日志显示每条结果的 Worker 编号和 Cookie 标识：

```
[抖音][W1|Cdy_01][硬编码] 有效 | 赞=76 评=22 转=1 播=0 | https://...
[头条][W2|无Cookie][DOM] 有效 | 赞=15 评=7 转=None 播=None | https://...
[快手][W1|Cks_02][硬编码] 有效 | 赞=19 评=None 转=None 播=3133 | https://...
```

字段含义：
- `W1`/`W2`/`W3`：浏览器编号
- `Cdy_01`：Cookie ID（数据库中的标识）
- `无Cookie`：该平台不需要 Cookie（如头条）

## 推荐配置方案

### 保守方案（高风控平台，如抖音、快手）
```python
BROWSER_STAGGER_MAX_SEC = 5.0
SLEEP_JITTER_RATIO = 0.5
VIEWPORT_RANDOM_OFFSET = 80
PLATFORM_CONCURRENCY = {"dy": 1, "ks": 1}
```

### 均衡方案（默认推荐）
```python
BROWSER_STAGGER_MAX_SEC = 3.0
SLEEP_JITTER_RATIO = 0.3
VIEWPORT_RANDOM_OFFSET = 50
```

### 激进方案（低风控平台，如头条）
```python
BROWSER_STAGGER_MAX_SEC = 1.0
SLEEP_JITTER_RATIO = 0.2
VIEWPORT_RANDOM_OFFSET = 30
PLATFORM_CONCURRENCY = {"toutiao": 5}
```
