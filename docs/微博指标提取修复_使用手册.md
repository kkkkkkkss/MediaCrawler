# 微博指标提取修复 — 使用手册

## 修复内容

修复微博平台视频帖子的播放量（`visit_count`）无法提取的问题。

## 影响范围

- 修改文件：`tools/fallback_field_map.py`
- 影响模式：`url_check`（链接检测 + 指标抓取）
- 影响平台：仅微博（wb）

## 修复前后对比

| 帖子类型 | 修复前 visit_count | 修复后 visit_count |
|----------|-------------------|-------------------|
| 视频帖子 | `None`（提取不到） | 正确数值（如 7110000） |
| 纯文字/图片帖子 | `None` | `None`（正常，微博不提供） |

## 使用方式

无需修改任何配置，修复后直接使用即可：

```bash
# CLI 模式
$env:PYTHONUTF8=1; uv run python main.py --type url_check

# API 模式
$env:PYTHONUTF8=1; uv run uvicorn api.app:app --host 0.0.0.0 --port 8888
# 然后上传含微博链接的 Excel 文件到 POST /api/v1/check/upload
```

## 注意事项

1. **纯文字/图片帖子**的浏览量在微博移动端接口中不可用，`visit_count` 会显示为空，这是微博接口的限制
2. **视频帖子**的播放量来自 `page_info.play_count` 字段，现在能正确提取
3. 支持中文数字格式解析（如 "1.2万"、"53万播放"），不会因格式问题丢失数据
