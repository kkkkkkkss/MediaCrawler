# 多格式返回 - 使用手册

## 功能说明

任务完成后可以选择 JSON 或 Excel 格式获取主结果和评论数据。

## 获取主结果

### 方式1：JSON 响应体（推荐程序化调用）

```
GET /api/v1/task/{task_id}/result/json
```

返回标准 JSON 对象，包含 `task_id`、`total`、`completed_at`、`results` 数组。

### 方式2：下载 Excel 文件

```
GET /api/v1/task/{task_id}/result?format=excel
```

返回 `.xlsx` 文件流。

### 方式3：下载 JSON 文件

```
GET /api/v1/task/{task_id}/result?format=json
```

返回 `.json` 文件流。

## 获取评论

前提：提交任务时需设置 `enable_comments: true`。

### 方式1：评论 JSON 响应体

```
GET /api/v1/task/{task_id}/comments
```

### 方式2：下载评论 JSON 文件

```
GET /api/v1/task/{task_id}/comments/download?format=json
```

### 方式3：下载评论 Excel 文件

```
GET /api/v1/task/{task_id}/comments/download?format=excel
```

## 前端操作

### 任务列表页

任务完成后，"下载"按钮变为下拉菜单，可选择：

- **Excel 文件** - 默认，点击按钮直接下载
- **JSON 文件** - 下载 `.json` 文件
- **查看 JSON 结果** - 弹窗预览，支持一键复制
- **评论 JSON** - 下载评论 JSON 文件
- **评论 Excel** - 下载评论 Excel 文件

### JSON 结果字段说明

| 字段 | 类型 | 说明 |
|------|------|------|
| id | int | 序号 |
| url | string | 原始 URL |
| platform | string | 平台代码(dy/ks/bili/wb/toutiao/xhs) |
| platform_name | string | 平台中文名 |
| content_type | string | 内容类型(视频/笔记/微博) |
| is_valid | bool | 是否有效 |
| author | string | 作者名 |
| title | string | 标题 |
| praise_count | int/null | 点赞数 |
| reply_count | int/null | 评论数 |
| visit_count | int/null | 播放/阅读量 |
| share_count | int/null | 转发/分享数 |
